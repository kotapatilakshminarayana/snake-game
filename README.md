# Snake Game

A classic Snake game built with pure HTML5, CSS, and JavaScript — no libraries or frameworks needed.

## Play Live

> After publishing, your live link will be:
> `https://YOUR-USERNAME.github.io/snake-game/`

## Features

- Smooth canvas-based gameplay
- Sound effects (eat, level-up, game over)
- Leaderboard with persistent scores (saved in browser)
- Level system — snake speeds up every 5 points
- Mute button
- Mobile-friendly on-screen controls
- Works in any modern browser

## How to Play

- Use **Arrow Keys** on keyboard, or the **on-screen buttons** on mobile
- Eat the red apple to grow and score points
- Avoid walls and your own tail
- Every 5 points = new level (faster speed)

## How to Run Locally

Just open `index.html` in any browser — no server needed!

```bash
git clone https://github.com/YOUR-USERNAME/snake-game.git
cd snake-game
open index.html
```

## Built With

- HTML5 Canvas API
- Web Audio API (for sound effects)
- Vanilla JavaScript
- localStorage (for leaderboard persistence)
